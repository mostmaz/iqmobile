# الصوت — ما ينقص الإعلان

الفيديو جاهز بالكامل بدون صوت. شيئان فقط ينقصانه، وكلاهما يُضاف بنسخ ملف
واحد إلى `public/audio/` ثم إعادة الرندر — لا تعديل على الكود.

```
public/audio/music.mp3   ← الموسيقى (تظهر في النسختين)
public/audio/vo.mp3      ← التعليق الصوتي (نسخة الـ VO فقط)
```

بعدها:

```bash
npx remotion render Ad-Reels out/deliver/Ad-Reels.mp4 --codec=h264
```

المكوّن يتحقق من وجود الملفين قبل تشغيلهما، فالرندر ينجح سواء وُجدا أو لا،
والموسيقى تنخفض تلقائياً إلى ٢٨٪ تحت التعليق الصوتي وترتفع إلى ٨٥٪ في نسخة
الموسيقى فقط.

---

## ١ · التعليق الصوتي

**يجب أن يسجّله عراقي حقيقي.** الطلب كان واضحاً بهذه النقطة وهو محق: أدوات
تحويل النص إلى كلام العربية تنزلق إلى الفصحى وتقتل الإعلان. لم أستخدم أي
منها.

النص، وتوقيت كل جملة كما هو مقطوع المونتاج عليها:

| الوقت | الجملة |
|---|---|
| 0:00.3 | تدوّر على موبايل مستعمل؟ |
| 0:02.2 | افتح IQ Mobile — أجهزة من كل المحافظات. |
| 0:05.2 | تشوف سعر المستعمل، وسعر الجديد جنبه. |
| 0:09.2 | وتتواصل مع البائع مباشرة، بدون تسجيل. |
| 0:12.3 | IQ Mobile. نزّله مجاناً. |

المطلوب: صوت شاب، إيقاع طبيعي غير متسرّع، تسجيل نظيف (mono أو stereo،
44.1kHz أو أعلى)، بدون موسيقى أو مؤثرات داخل الملف — الموسيقى تُضاف هنا.
الطول الإجمالي ١٥ ثانية بالضبط، والجملة الأخيرة تنتهي قبل 0:14.6.

## ٢ · الموسيقى

مقطوعة مرخّصة، خفيفة وإيقاعها صاعد، ١٥ ثانية. لم أُدرج أي مقطوعة لأن
الموسيقى تحتاج ترخيصاً، واستعمال مقطوعة غير مرخّصة يعرّض الإعلان للحجب على
انستغرام ويوتيوب.

مصادر مناسبة: Epidemic Sound · Artlist · Uppbeat (فيه مجاني مع نسبة) ·
YouTube Audio Library (مجاني بالكامل).
