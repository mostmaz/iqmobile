# Listing-quality guidance

Optional corrections appear on the model, description, photo, and review steps, with Edit buttons returning to the relevant fields. The existing three-photo requirement remains unchanged.

Generic or brand-only model names receive clarification prompts; numeric and manual model names remain valid. Photo hints count distinct selections without inspecting image content.

New devices receive box/seal/activation prompts. Used, repaired, and refurbished devices receive screen, body, and repair-history prompts, including stating unknown repair history honestly.

Arabic and English completeness heuristics are advisory and cannot verify device condition or truth. No server/schema changes; requires a mobile release.

Validation: six listing-quality tests and mobile TypeScript check passed.
